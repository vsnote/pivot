# Pivot 品牌图标资产

## 来源
- Claude、OpenAI、DeepSeek、Google Gemini、OpenRouter、Ollama、LM Studio、Mistral AI、Perplexity、Hugging Face、NVIDIA、Cloudflare、Replicate、GitHub：Simple Icons 第三方品牌图标集合。SVG 原稿保存在本目录。OpenAI 下载自 https://cdn.jsdelivr.net/npm/simple-icons@latest/icons/openai.svg ，其他图标下载自 https://cdn.simpleicons.org/ 对应品牌 slug。
- 硅基流动：https://siliconflow.cn/logo-new.svg；`siliconflow-icon.svg` 从品牌字标中提取图形部分，未重新绘制路径。
- xAI：https://raw.githubusercontent.com/lobehub/lobe-icons/master/packages/static-svg/icons/xai.svg （Lobe Icons 第三方图标集合）。替换此前误用的 X 社交平台标识。

## 使用
- `*-128.png`：透明高清渲染版本，设计画布中使用；SVG 原稿保留用于开发集成。
- `x.svg` / `x.png` 为历史资产，不应用于 xAI。
- Simple Icons 与 Lobe Icons 并非品牌官方资产发布渠道；上线前需核对各品牌商标规范与相应许可。
- 展示 Logo 不代表 Pivot 已实现该服务商的协议、认证或模型发现能力。
